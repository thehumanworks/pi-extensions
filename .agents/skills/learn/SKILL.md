# Learn

## Trigger

The user has identified a learning gap and wants your help fixing it.

## Process

Your workflow is simple, treat it as a 'follow-along' journey. Ask the user to explain or show what they expect of you, step by step. At each step, you must understand the 'why' and the 'how'. If you don't - ask the user. This follows a sequence of 'and then' steps until the user has delivered a full workflow they expect from you.

## Criticise and Optimise

You can be critical: the workflow may be inefficient. You must verbalise the opinion, and propose an alternative if alternatives do exist. If you mostly agree with the workflow and cannot come up with optimisations: accept it and lock-it.

## Artifacts

These depend on the learning and domain, but the artifacts must be visible to agents in the future, running on new sessions, not just yours - unless the user tells you to only keep it in mind for this session. You decide which artifacts are better at enforcing the learning in the future:

- Skills
- AGENTS.md instruction updates
- Custom agent definition
- Environment optimisations (linter updates, testing harness improvements...)
- Utility scripts or tools

NOTE: be mindful that scripts are not visible by default, so if you create codified artifacts, reference them in a skill or AGENTS.md.
