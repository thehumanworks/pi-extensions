# Claude Fable review, checkpoint 4

**Verdict: the patch closes both checkpoint-3 defects and leaves source, scope, and expiry validation intact. No blocker.** Apply it after the frozen runs as planned.

**Defect 1, retry loop.** Curate-phase failures are now per candidate: operations are grouped by index, a candidate with zero or two operations is rejected alone, and every supersede check plus `reconcile` runs inside a per-candidate try. The four guards that matter are unchanged and still enforced per operation: short cannot supersede long, tool output cannot supersede user memory, cross-scope supersession, and double supersession. Completed-but-invalid output is distinguished from transport failure by `InvalidCaptureOutput`, and only that class checkpoints the delta. Abort, provider error, store I/O, and the abort-signal throw after the call all remain ordinary errors that keep the pending delta. The backfill loop terminates correctly with the new return shape because the delta is marked processed. The tests at the malformed-output, transport-failure, sibling-survival, and length cases cover exactly the paths I named.

**Defect 2, false attachment.** The three standalone examples from my review are now tests and I traced each through the new matcher. "Until DATE, use 1 worker" fails the whole-clause qualifier rule in both directions, so the durable retry limit stays long. A bare following "Until DATE" attaches, a preceding one attaches only as a colon heading, and anaphoric forms require a copula plus a qualifier. The existing mixed-message, Larch, and laundering tests still hold because "Temporarily use 1 worker until DATE" is not a bare qualifier, which is the same outcome as before.

**Token literals.** The new `containsLiteral` boundary check makes "300" and "v3" and timestamps stop excusing removal of "3". Decimals are guarded on both sides. Correct.

**One important tradeoff.** A completed reflect call that stops with `length` now permanently skips that delta instead of looping. That case is realistic: a dense 80-entry delta with long quoted excerpts can exceed the 5,000-token output cap. Before the patch this was a paid loop; after it the evidence is silently skipped, and because index.ts is frozen the outcome only reaches a trace file, not a user notice, since the old throw path produced the error notification. Same for a malformed curate envelope, which discards an entire validated reflect batch. Recommend two post-freeze follow-ups, not changes to this patch: notify the user when a rejection carries candidate index minus one, and on a `length` stop re-run once with half the delta.

**Minor, optional.** The anaphora rule accepts only is, are, and remains, so "This applies only until DATE" does not attach. That is not a regression, since the old `TEMPORARY` pattern never matched an ISO "until" and so never linked it either, but adding applies, holds, and lasts to the verb list would close it in one line. The heading rule will not match "Temporary for this incident:" because the period alternative lacks a "for this" form. Both can wait.
